# Skill: sorting-advisor

## 描述
多物品清单式垃圾分类讲解。逐件调用分类工具查询，最后用表格汇总。查不到的物品明确告知，不编造。

## 何时使用
当用户一次性询问多个物品的垃圾分类时使用本 Skill，例如"外卖餐盒、废旧电池和快递纸箱分别是什么垃圾？"。

## 执行步骤
1. 识别用户询问的全部物品（通常 2-5 个）。
2. 对每个物品逐件调用 `waste_sorting_lookup` 工具查询。
3. 如果某物品查不到（返回"未找到"），明确告知用户"该物品暂未收录"，不编造分类。
4. 汇总查询结果，用 Markdown 表格输出：

   | 物品 | 分类 | 投放提示 |
   |------|------|---------|
   | ... | ... | ... |

5. 表格后附一句总结提示，如"有害垃圾需投入专用收集容器"等针对性建议。

## 约束
- **绝不编造分类**：工具查不到就说查不到，引导用户换词再试。
- 分类口径参照《上海市生活垃圾管理条例》等公开资料，仅供参考。
- 每件物品的投放提示直接来自工具返回，不要自行补充。
