# Skill: sorting-advisor

## 适用场景
用户问"XX是什么垃圾"或多物品分类查询时触发。

## 工作步骤
1. 识别用户提到的所有物品名称
2. 对每个物品逐个调用 `waste_sorting_lookup` 查询
3. 收集所有查询结果
4. 用 Markdown 表格汇总：| 物品 | 分类 | 投放提示 |
5. 查不到的物品在表格中标注"未收录，建议换词查询"，不编造

## 约束
- 分类信息只能来自 `waste_sorting_lookup` 工具返回
- 查不到时明确告知，可用模糊匹配引导换词
- 绝不凭记忆编造分类结论
